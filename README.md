# 💰 Finance KPI Dashboard

## 1. Project Overview

An interactive Finance KPI Dashboard developed using Microsoft Excel to analyse financial performance, monitor key metrics, and provide insights into revenue, profit, expenses, and customer performance.

## 2. Project Objectives

- Monitor revenue, profit and expenses.
- Compare budgeted profit with actual profit.
- Analyse monthly financial performance.
- Evaluate department-wise revenue and expenses.
- Understand expense distribution.
- Identify top customers by revenue.

## 5. Key Performance Indicators

- Total Revenue
- Actual Profit
- Total Expenses
- Total Customers
- Customer Satisfaction Score

## 6. Dashboard Features

- Monthly and regional interactive filters.
- Revenue vs Profit Trend Analysis.
- Revenue by Department.
- Revenue, Expenses and Actual Profit Comparison.
- Budget vs Actual Profit Analysis.
- Expense Breakdown.
- Top 10 Customers by Revenue.

## 7. Key Business Insights

- Compare monthly revenue and actual profit trends.
- Identify departments generating the highest revenue.
- Evaluate differences between budgeted and actual profit.
- Understand the distribution of business expenses.
- Identify high-revenue customers.
